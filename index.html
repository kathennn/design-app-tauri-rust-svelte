The toolkit

Six skills. One coherent workflow.

Use each specialist independently or coordinate them across the software lifecycle.

01 / ORCHESTRATION

project-orchestrator

Coordinates discovery, planning, implementation, validation and release.

02 / RESEARCH

research-engineer

Investigates APIs, libraries, platform constraints and technical trade-offs.

03 / IMPLEMENTATION

fullstack-developer

Builds Svelte 5 and TypeScript interfaces with Tauri 2 and Rust logic.

04 / QUALITY

software-analyst

Reviews architecture, security, maintainability, tests and release readiness.

05 / DELIVERY

project-manager

Plans milestones, tasks, risks, dependencies and acceptance criteria.

06 / DOCUMENTATION

technical-writer

Creates developer docs, setup guides, architecture notes and release updates.

Simple installation

Ready in one command.

  1. Run the installer from your project directory.
  2. Choose local or global installation and target agents.
  3. Reload your agent if it does not discover skills automatically.

Requires Node.js 18+. No runtime dependencies.
